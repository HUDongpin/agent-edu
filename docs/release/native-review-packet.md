# Native review working packet

`npm run review:packet` creates a side-by-side Markdown aid for a qualified
native-language reviewer. It is generated bulk text, not evidence, and it does
not approve a locale or alter any release state.

```bash
npm run review:packet            # all eight non-English site locales
npm run review:packet -- de ar   # selected locales
```

The files are written below `review-packets/`, which is gitignored. Each packet
records the current commit, an exact hash of its message/release/review inputs,
whether the source tree was dirty, and the approval-ledger states observed
before generation. Regenerate it after any covered input changes.

## Scope comes from the current release contracts

The generator discovers `messages/**/en.json` rather than maintaining a fixed
three-catalog list. For each target locale it then applies the current generated
release surface:

- core `main`, `handbook`, and `widgets` namespaces are included;
- a published course namespace is included only when that locale is in the
  course's reviewed-content set;
- blocked namespaces are listed as excluded and never smuggled into the public
  review scope;
- an explicit English fallback is listed as a boundary, not misreported as
  hundreds of missing translations.

This is especially important for Codex. Its exact-bundle review ledger remains
`pending` until qualified human evidence is recorded against current bytes. A
packet reports that state and excludes the blocked namespace; generation never
edits `lib/codex/localization-reviews.json` or turns its rows into approvals.

## What the packet checks automatically

Rows are flattened from nested objects and arrays and grouped into manageable
screen/topic sections. The automatic note identifies:

- missing or extra keys;
- leaf-type, placeholder, or emphasis-marker mismatches;
- values identical to English without a current key-specific exception; and
- identical values covered by a named `i18n-exceptions.json` record.

Widget plural rows follow the same bounded `Intl.PluralRules` categories used
by the source key gate. The summary calculates the current row and English-word
counts at generation time; no historical string or word count is treated as a
budget fact.

## What remains human and rendered

The packet cannot establish semantic accuracy, natural register, terminology
quality, line wrapping, bidi isolation, RTL layout, focus order, screen-reader
speech, media text, or production behavior. Reviewers must still use the
official native-review form, the CSV generated by the release-grade i18n audit,
and the required frozen browser/deployment evidence.

Do not commit a packet as a conclusion. Record only the sanitized, scope-bound
review result through the existing release-evidence process, and keep every
pending or failed finding visible.
