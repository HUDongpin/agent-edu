## Frame

The course must teach one falsifiable capability: a learner can turn an accountable creative intent and rights-bounded source set into one playable, locally verified 9:16 candidate while preserving an auditable path to a human release or do-not-publish decision.

The old control skeleton was valuable:

`intent → assets/rights → evidence → plan → preview → execution → verification → human decision`

The prior implementation did not prove that capability. It proved Markdown shape and a browser-only selection fixture, while course language implied real media execution and beginner-to-advanced coverage.
