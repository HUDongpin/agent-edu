## Important disagreements retained rather than erased

1. Google gives a broad recommendation in favor of few-shot examples; other current guidance and measured model behavior make this non-universal. Course 7 turns the disagreement into a controlled experiment.
2. Older prompt-engineering repositories describe techniques that may be less useful or differently implemented in current reasoning models. Course 7 retains them as taxonomies and requires model-specific validation.
3. Provider formatting guidance can improve parsing, but none of it makes a delimiter a security sandbox. Course 7 combines interpretation rules with application controls.
4. Schema-conforming output and factual grounding are different dimensions. The course now evaluates both separately.

## Source hierarchy used

1. Current official course pages for curriculum attribution.
2. Current first-party provider documentation for model behavior and product-sensitive guidance.
3. Official GitHub repositories with declared licences for corroboration and examples.
4. Community GitHub taxonomies for discovery only, with claims checked against first-party sources.
5. No unofficial mirror, copied assignment, leaked notebook, or answer repository was used.
