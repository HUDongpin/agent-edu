All 14 figures are technically available for development and internal review.
In the machine ledger, `status: available` means technical/local availability
only; it does not mean publication rights are cleared. The current rights state
is `rights-review-required`, and the public release gate remains closed until an
evidence-bearing publication basis has been reviewed.

Each figure has three local renditions: one PNG master and two responsive WebP
derivatives. Video-derived figures are single stills, not redistributed videos.
The course labels current, dated-current, and historical interfaces so a visual
is not mistaken for a guarantee about the latest release.

The privacy review found no API keys, tokens, credentials, email addresses,
learner-supplied private content, unrelated applications, or private browser
tabs. Some unaltered first-party figures nevertheless retain identifiers that
Cursor itself published in its public demos: `fig-03` includes a demo Draft PR
URL; `fig-06` a demo local path and repository remote; `fig-10` the recognizable
official lesson presenter; `fig-11` a demo local path; and `fig-14` a demo
account name and avatar. These disclosures do not imply that the referenced
repositories are publicly accessible. They must remain part of the publisher's
final privacy and publication-rights review.
