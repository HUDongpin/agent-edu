## 7. 威脅模型與對抗性測試

運行下面所有 12 個命名案例。如果一行組合了相關變體，則練習每個變體並在該行中保留單獨的觀察結果。

| 案件 | 資產或邊界 | 強制控制 | 預期訊號 | 觀察結果 |
| --- | --- | --- | --- | --- |
| 1 | 提示或結果注入 | 將傳回的內容保存在不受信任的資料通道中 | 注入不能改變更高優先順序的政策 |  |
| 2 | 惡意註解或隱藏指令 | 將註釋視為提示；檢查內容區塊 | 沒有權威或政策提升 |  |
| 3 | 路徑遍歷 | 規範化並限制允許的路徑 | 超出範圍的路徑被拒絕 |  |
| 4 | 超大內容 | 強制執行位元組、項目和上下文限制 | 有界拒絕或安全截斷訊號 |  |
| 5 | 架構繞過或未知字段 | 驗證 JSON 架構並拒絕額外內容 | 確定性無效參數結果 |  |
| 6 | 錯誤的受眾或令牌傳遞 | 驗證受眾；從不向上游轉發客戶端令牌 | 請求被拒絕且令牌未洩漏 |  |
| 7 | 重定向、SSRF 或 DNS 重新綁定 | 將目的地列入白名單並重新驗證每個躍點 | 內部或不允許的目標被阻止 |  |
| 8 | 狀態句柄重播 | 使用不可預測的句柄並重新授權每個請求 | 跨用戶或過期重播被拒絕 |  |
| 9 | 重複寫入 | 冪等性或精確修訂保護 | 最多一項預期的改變 |  |
| 10 | 取消比賽 | 合作取消加上取消後狀態檢查 | 無隱藏的後期副作用 |  |
| 11 | 包或端點妥協 | 固定不可變的出處並執行停用路徑 | 可以隔離受損的集成 |  |
| 12 | 上行超時 | 截止日期、有限重試和清晰的錯誤映射 | 沒有無限掛起或重複效果 |  |

## 10. 停用和恢復演練

- 禁用一台伺服器或工具；
- 撤銷其憑證；
- 從經過編輯的日誌中識別其最近的操作；
- 恢復已知良好的配置；
- 驗證舊伺服器無法運作；
- 記錄時間、負責人、故障、後續工作。
