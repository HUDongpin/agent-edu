## 4. عقود القدرة

لكل أداة، ومورد، وموجه، واستنباط، وامتداد تم التفاوض عليه، سجل:

- الاسم أو URI؛
- صاحب التفاعل؛
- مخطط الإدخال والإخراج؛
- قاعدة التفويض والموافقة؛
- سلوك عادي، وفارغ، وغير صالح، وغير مصرح به، وتعارض، ومهلة، وفشل في المنبع؛
- عادت الأدلة؛
- التراجع أو التعويض عن الكتابة.

## 5. الأدلة البروتوكولية المباشرة

- `server/discover` request/response مع البيانات الوصفية الحالية لكل طلب و`resultType`؛
- آثار list/read/get/call البدائية؛
- آثار الفشل العادية والمتوقعة؛
- سجل التنقيح؛
- ملاحظة لأي واجهة مستخدم Legacy Inspector يتم الاحتفاظ بها كدليل تاريخي فقط.

## 6. استضافة أدلة التكامل

- اسم المضيف والإصدار الدقيق؛
- هوية النقل والخادم التي تم تكوينها؛
- البروتوكول والقدرات التي تم التفاوض عليها؛
- القائمة المسموح بها للأدوات الفعالة وسياسة الموافقة؛
- سير عمل ناجح للقراءة فقط؛
- سير عمل مرفوض أو متوقع الفشل.

## 7. نموذج التهديد واختبارات الخصومة

قم بتشغيل جميع الحالات الـ 12 المذكورة أدناه. إذا كان صف واحد يجمع بين المتغيرات ذات الصلة، قم بممارسة كل متغير والاحتفاظ بملاحظات منفصلة في هذا الصف.

| قضية | الأصول أو الحدود | السيطرة القسرية | الإشارة المتوقعة | النتيجة الملحوظة |
| --- | --- | --- | --- | --- |
| 1 | الحقن الفوري أو النتيجة | احتفظ بالمحتوى الذي تم إرجاعه في قناة بيانات غير موثوقة | لا يمكن للحقن أن يغير سياسة الأولوية العليا |  |
| 2 | التعليقات التوضيحية العدائية أو التعليمات المخفية | التعامل مع التعليقات التوضيحية كتلميحات؛ فحص كتل المحتوى | لا سلطة أو سياسة الارتفاع |  |
| 3 | اجتياز المسار | تحديد المسارات المسموح بها وتقييدها | تم رفض المسار خارج النطاق |  |
| 4 | محتوى كبير الحجم | فرض حدود البايت والعنصر والسياق | رفض محدود أو إشارة اقتطاع آمنة |  |
| 5 | تجاوز المخطط أو الحقول غير المعروفة | التحقق من صحة مخطط JSON ورفض الإضافات | نتيجة حتمية غير صالحة للمعلمات |  |
| 6 | جمهور خاطئ أو عبور رمزي | التحقق من صحة الجمهور؛ لا تقم أبدًا بإعادة توجيه رموز العميل إلى المنبع | تم رفض الطلب دون تسرب الرمز المميز |  |
| 7 | إعادة التوجيه أو SSRF أو إعادة ربط DNS | قم بإدراج الوجهات في القائمة المسموح بها وأعد التحقق من صحة كل قفزة | تم حظر الهدف الداخلي أو غير المسموح به |  |
| 8 | إعادة تشغيل مقبض الحالة | استخدم مقابض غير متوقعة وأعد تفويض كل طلب | تم رفض إعادة التشغيل عبر المستخدمين أو منتهية الصلاحية |  |
| 9 | كتابة مكررة | العجز أو حارس المراجعة الدقيقة | تغيير مقصود واحد على الأكثر |  |

| 11 | تسوية الحزمة أو نقطة النهاية | قم بتثبيت مصدر غير قابل للتغيير ومسار تعطيل التمرين | يمكن عزل التكامل المنقوص |  |
