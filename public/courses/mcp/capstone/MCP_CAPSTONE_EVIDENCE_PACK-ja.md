## 7. 脅威モデルと敵対的テスト

以下の 12 個の名前付きケースをすべて実行します。 1 つの行に関連するバリアントが結合されている場合は、各バリアントを実行し、その行に個別の観測値を保持します。

| 場合 | 資産または境界 | 強制制御 | 期待される信号 | 観測結果 |
| --- | --- | --- | --- | --- |
| 1 | プロンプトまたは結果の注入 | 返されたコンテンツを信頼できないデータ チャネルに保持する | インジェクションでは優先度の高いポリシーを変更できません |  |
| 2 | 敵対的な注釈または隠された指示 | 注釈をヒントとして扱います。コンテンツブロックを検査する | 権限やポリシーの昇格なし |  |
| 3 | パストラバーサル | 許可されたパスを正規化して制限する | 範囲外のパスが拒否されました |  |
| 4 | サイズの大きいコンテンツ | バイト、項目、およびコンテキストの制限を強制する | 境界付き拒否または安全な切り捨て信号 |  |
| 5 | スキーマバイパスまたは不明なフィールド | JSON スキーマを検証し、余分なものを拒否する | 決定的な無効パラメータの結果 |  |
| 6 | 間違った対象ユーザーまたはトークンのパススルー | 対象読者を検証します。クライアントトークンを上流に転送しないでください | トークン漏洩なしでリクエストが拒否されました |  |
| 7 | リダイレクト、SSRF、または DNS リバインド | 宛先を許可リストに登録し、すべてのホップを再検証する | 内部ターゲットまたは許可されていないターゲットがブロックされました |  |
| 8 | ステートハンドルの再生 | 予測できないハンドルを使用し、各リクエストを再承認する | クロスユーザーまたは期限切れのリプレイは拒否されました |  |
| 9 | 重複書き込み | べき等性または正確なリビジョン ガード | 意図した変更は最大 1 つまで |  |
| 10 | キャンセルレース | 連携キャンセルとキャンセル後の状態確認 | 隠れた遅発性副作用なし |  |
| 11 | パッケージまたはエンドポイントの侵害 | 不変の来歴を固定し、パスを無効にする | 侵害された統合を隔離できる |  |
| 12 | アップストリームのタイムアウト | 期限、制限付き再試行、エラー マッピングのクリア | 無限のハングや重複効果はありません |  |

## 10. 無効化と回復の訓練

- 1 つのサーバーまたはツールを無効にする。
- その資格情報を取り消します。
- 編集されたログから最近のアクションを特定します。
- 正常な構成を復元します。
- 古いサーバーが動作できないことを確認します。
- 時間、所有者、障害、フォローアップ作業を記録します。
