# Mathematical animation project context

This project uses Manim Community at the revision recorded in `SOURCE_SNAPSHOT.json`. It does not use ManimGL.

## Required loop

1. Explore the repository, environment, and `SCENE_CONTRACT.md`.
2. State a short implementation plan and identify missing dependencies.
3. Change only the named scene and test files.
4. Run the mathematical test.
5. Render a low-quality preview.
6. Inspect start, quarter, midpoint, three-quarter, and final frames.
7. Report commands, exit results, artifact paths, and uncertainty.

`CLAUDE.md` provides context. The mathematical assertions and release scripts provide enforcement. If a visual judgment cannot be established by a test or inspected frame, mark it for human review.
