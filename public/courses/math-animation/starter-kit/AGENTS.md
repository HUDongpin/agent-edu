# Mathematical animation project instructions

- Read `SCENE_CONTRACT.md` before changing code.
- This starter uses Manim Community. Never introduce `manimgl` imports or commands.
- Use only the pinned repository revisions in `SOURCE_SNAPSHOT.json`.
- Run `manim/test_math_truth.py` before and after a scene change.
- Render low quality before any final-quality export.
- Drive every dependent visual from the same `h` tracker.
- Keep the mathematical function independent from rendering callbacks so it can be tested.
- Do not add a dependency, font, image, audio file, provider call, or third-party skill without an explicit license and security review.
- Do not print or store credentials, tokens, cookies, signed URLs, or private media.
- Before completion, report the exact command, exit result, output path, sampled-frame paths, mathematical test, media probe, visual review, and unresolved boundary.
