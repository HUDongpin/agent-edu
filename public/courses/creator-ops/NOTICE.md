# Course 16 — Creator Operations: source, rights, and safety notice

Last reviewed: 2026-08-26  
Course: `aicourse.top/[locale]/creator-ops/`

## What this course publishes

Course 16 publishes original aicourse.top prose, semantic HTML, CSS, exercises,
checkpoints, templates, and diagrams. Its operating model treats an editorial
agent as a bounded system for research, production, review, authorized
distribution, measurement, and learning. Human approval remains mandatory
before any externally visible publication or account action.

## Link-only use of GitHub

GitHub repositories are linked as inspectable implementation evidence and
licensing cases. No third-party code or media is copied into the course: this
includes source code, README prose, screenshots, logos, diagrams, example
images, video, audio, model weights, datasets, templates, and bundled assets.
The website does not vendor, mirror, execute, or redistribute the referenced
repositories.

A GitHub link is not an endorsement, a security review, or permission to reuse
everything visible in a repository. Upstream licenses, file-level notices,
model cards, media rights, plugin terms, service terms, and target-platform
rules remain applicable. Repository license links in the course are evidence
about the identified repository snapshot only; they are not legal advice or a
blanket clearance for dependencies, models, outputs, or deployments.

## Decision register

Every source record has one of three bounded decisions. The decision applies to
the course use described here, not to every possible use of the project. The
2026-08-26 release ledger contains 13 PASS, 10 CONDITIONAL, and 4 EXCLUDED
records; each is anchored to a 40-character Git commit SHA.

### PASS

`PASS` means the repository may be linked as an implementation reference for a
specified course capability. A PASS does not waive API access, deployment,
privacy, copyright, trademark, model, media, plugin, connector, or
target-platform obligations. Learners must still pin and test the version they
actually use, review transitive dependencies, and obtain all necessary rights.

### CONDITIONAL

`CONDITIONAL` means the repository may be linked for a carefully bounded case,
but hands-on adoption requires the condition recorded in the source register to
be satisfied. Typical conditions include AGPL network-interaction duties or GPL distribution duties;
separate model, voice, face, music, codec, plugin, or custom-node rights;
owned or expressly authorized browser targets; consent and privacy controls;
and current platform or connector terms. Technical capability never substitutes
for authorization.

### EXCLUDED

`EXCLUDED` means the repository is retained only as a negative licensing,
authorization, or architecture case. It is not part of the runnable course
stack and must not be installed, invoked, packaged, adapted, or exercised in a
Course 16 lab. The four excluded records are the n8n and Dify licensing cases,
MoneyPrinterTurbo, and MediaCrawler.

The release phrase `not installed, invoked, packaged, adapted, or exercised` is
literal. 中文解释：不得安装、调用、打包、改编或以任何形式进入课程实操；下列
MoneyPrinterTurbo 与 MediaCrawler 只能作为排除案例阅读，不能成为实验依赖。

## Explicit hands-on exclusions

### MoneyPrinterTurbo — EXCLUDED

MoneyPrinterTurbo is discussed only to decompose a “one-click video” promise
into inspectable stages: script, rights-cleared assets, rendering, human review,
and authorized publishing. It is EXCLUDED from all hands-on work. Course 16 does
not install, run, copy, package, adapt, or call it, and does not exercise its
third-party auto-upload paths. Its MIT code license does not establish the
provenance or reuse rights of bundled/default music, stock media, generated
outputs, service integrations, or target-platform actions.

### MediaCrawler — EXCLUDED

MediaCrawler is discussed only as a negative authorization and licensing case.
It is EXCLUDED from all hands-on work. Course 16 does not install, run, copy,
package, adapt, or call it; does not provide or reuse platform cookies or login
state; and does not crawl social-platform content with it. Its custom
non-commercial learning license and anti-large-scale-crawling conditions do not
fit this public, commercially relevant creator-operations course. Platform
authorization, privacy, copyright, database rights, robots directives, rate
limits, and current terms would remain separate constraints in any event.

## Distribution and browser-automation boundary

The core course uses official APIs, official connectors, owned publishing
surfaces, or explicitly authorized test fixtures. Human approval is required at
the final distribution gate. The labs prohibit CAPTCHA bypass, stealth or proxy
evasion, bulk posting, account farming, scraping behind login, reuse of another
person's session state, and actions on third-party accounts or surfaces without
written authority. A technically successful browser action is not evidence of
permission or publication quality.

The exact release requirement is `human approval` before every externally
visible publication or account action. 中文解释：任何对外发布或账号操作都必须先由
明确的人类责任人审阅并批准；智能体、自动化规则或模型评分不能代替该批准。

## Media, identity, and measurement boundary

Learners may process only media they own or are authorized to use. Model and
voice licenses are reviewed separately from framework licenses. A real person's
voice, face, likeness, identity, or distinctive style must not be cloned or
imitated without explicit documented consent and an appropriate rights review.
Transcripts, generated assets, captions, factual claims, names, quotations, and
numbers require human verification before release.

Analytics is limited to consent-aware, first-party measurement on owned
destinations. Observational analytics does not establish causation, and content
credentials report signed provenance assertions rather than proving that an
underlying event is true or that every right has been cleared.

## Corrections and version review

The source register records a canonical repository URL, immutable 40-character
commit SHA, commit timestamp, license URL pinned to that same revision, access
date, bounded snapshot note, decision, supported use, and explicit boundary in
English and Simplified Chinese. Section evidence chips open the pinned source
tree rather than a floating default branch. Before implementation, re-check the
selected release or commit, security notices, licenses, model and media terms,
connector scopes, platform policies, quotas, costs, and privacy requirements.

If a source owner or contributor identifies an attribution, licensing, privacy,
security, or factual issue, please use the site's public repository/contact path
and cite the affected Course 16 module and source record.
