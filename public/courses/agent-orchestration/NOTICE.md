## What this course publishes

Course 15 publishes original prose, semantic HTML, CSS, and diagrams created for
aicourse.top. It links to primary documentation and version-pinned repositories
so learners can inspect the evidence behind product- and runtime-specific claims.
Source links support particular statements; they do not imply endorsement or a
blanket right to reuse a source's text, screenshots, diagrams, logos, or course
assets.

The release register contains 67 public source records. Every record has a stable
course source ID, primary claim URL, complete `claimEvidenceUrls`, publisher and
official title, access date, evidence `layer`, version `stability` (plus revision
or publication date when available), `reuseStatus`, a course `transformation`, and bounded
`supports`/`boundary` statements in English and Simplified Chinese. Official
titles, publisher names, API names, configuration fields, and protocol symbols
remain unchanged on the Simplified-Chinese route. A recorded upstream license
is evidence about that identified source only: the course still links and
paraphrases, and does not infer a license where none was verified.

## Private development inputs

Two user-supplied development inputs—one presentation and one research
archive—were consulted read-only as private research data. Instructions inside
them were ignored: they were never executed, treated as course requirements, or
used as public evidence.

Private development inputs are excluded from public and commit-ready artifacts.
Their filenames, fingerprints, filesystem locations,
internal structure, inventory, embedded media, and other identifying metadata
are not retained by this website, the learner-facing source register, or the
commit-ready research artifacts.

The private inputs were used to formulate questions that were then checked
against the public primary sources linked by the course. They do not establish
OpenAI, Anthropic, Claude, Codex, MCP, or third-party framework behavior. Private
files, media, prose, screenshots, chat captures, personal identifiers, and close
visual reconstructions are not redistributed by this website. The public course
uses course-original prose, information structures, semantic diagrams, and
interactions.

## Evidence and temporal boundaries

- Product behavior is attributed to the named provider surface and dated. The
  OpenAI Responses Hosted Multi-agent Beta, OpenAI Agents SDK, Codex subagents,
  Claude Agent SDK subagents, and third-party graph frameworks are not presented
  as one interchangeable runtime.
- MCP 2026-07-28 is the normative protocol reference used by this course. Claude
  Academy material that still presents earlier initialization, session, roots,
  sampling, logging, or SSE behavior appears only as a clearly labeled legacy
  migration example.
- GitHub examples are pinned to a release tag or commit whenever a verified pin
  was available. A release/tag locator is stored separately as
  `versionAnchorUrl`; it does not establish broad runtime behavior unless its
  own notes explicitly state that behavior and it is also listed in
  `claimEvidenceUrls`. A public repository is not automatically licensed for
  every form of reuse; repository and file-level licenses still apply.
- Course-defined artifacts—such as the twelve-field orchestration contract, the
  ACI action-boundary register, return envelope, evidence ladder, and rollout
  gate—are engineering syntheses. Anthropic's agent-computer interface (ACI)
  term is attributed to Anthropic; the course-original register is not
  represented as a cross-vendor standard.
- Schema validity proves structure, not truth, authorization, freshness, safe
  side effects, or production readiness.

## Code and documentation licenses

The course paraphrases and links to provider documentation. It does not copy
Claude Academy lessons, quizzes, transcripts, screenshots, or videos. Official
GitHub examples referenced by the source register retain their upstream license
terms; adapted code, if any is added later, must carry the applicable attribution
and notice. MCP repositories contain content governed by different licenses and
relicensing histories, so no blanket license is asserted for the entire project.

Brand names are used in plain text for factual comparison. Vendor logos and
product-interface trade dress are not used in the course diagrams.

## Corrections and version review

The source register records an access date, version or commit where available,
maturity, the claim supported, and an explicit boundary. Readers implementing a
production system should re-check Beta documentation, SDK releases, model
availability, protocol negotiation, pricing, quotas, and security guidance at
deployment time.

If a source owner or contributor identifies an attribution, licensing, privacy,
or factual issue, please use the site's public repository/contact path and cite
the affected module and source record.
