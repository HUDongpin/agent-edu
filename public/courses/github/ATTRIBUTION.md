# GitHub course figure attribution

The 21 interface figures in this directory are authentic GitHub Docs assets,
not simulated interface artwork. They were downloaded on 2026-08-23 and
reverified byte-for-byte on 2026-08-24 against the `github/docs` repository at commit
`4f8c3170cea7f72cf41fc976f5dbf4e8a0b8567f`.

GitHub Docs content and assets are made available under the
[Creative Commons Attribution 4.0 International licence](https://creativecommons.org/licenses/by/4.0/).
The figures are attributed in the course interface as:

> GitHub Docs (c) GitHub, Inc. - CC BY 4.0 - verified 2026-08-24

The complete, machine-checkable record for every figure is in
`lib/github/figures.ts`. Each record preserves:

- the local PNG and WebP paths;
- original dimensions and the PNG SHA-256 digest;
- the live GitHub Docs asset URL;
- an immutable raw URL pinned to the commit above;
- the GitHub Docs page where the figure is taught;
- the licence, observation date, and privacy-review status.

The local copies are included for stable, privacy-preserving instruction. The
course does not use the GitHub logo as its own identity. aicourse.top is an
independent learning resource and is not affiliated with or endorsed by GitHub,
Inc.
